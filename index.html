❓ Interview Questions & Answers

1. What is clustering?
Clustering is an unsupervised machine learning technique that groups similar data points together based on their features, without predefined labels. The algorithm finds patterns and structures in data by grouping items that are more similar to each other than to items in other groups.

Key characteristics:
• Unsupervised learning (no target variable)
• Groups similar data points together
• Discovers hidden patterns in data
• Used for customer segmentation, anomaly detection, and data exploration

Applications: Customer segmentation, image segmentation, document clustering, anomaly detection, recommendation systems
2. Why does scaling matter in KMeans?
KMeans uses Euclidean distance to measure similarity between data points. Features with larger scales (e.g., income in thousands) will dominate the distance calculation over features with smaller scales (e.g., spending score 1-100).

Without scaling:
• Features with larger ranges dominate clustering decisions
• Income (range: 15-137k) would overshadow Spending Score (range: 1-100)
• Results in biased and inaccurate clusters

StandardScaler solution:
• Transforms each feature to mean=0 and std=1
• All features contribute equally to distance calculations
• Formula: X_scaled = (X - mean) / std
• Ensures balanced clustering based on all features
3. What is inertia?
Inertia (also called Within-Cluster Sum of Squares - WCSS) measures how tightly grouped the clusters are. It's the sum of squared distances between each data point and its assigned cluster centroid.

Formula:
Inertia = Σ ||xᵢ - μⱼ||² for all points xᵢ in cluster j with centroid μⱼ

Properties:
• Lower inertia = tighter, more compact clusters
• Higher inertia = loose, spread-out clusters
• Decreases as K (number of clusters) increases
• At K=n (n=number of points), inertia=0 (each point is its own cluster)

Use in Elbow Method: Plot inertia vs K to find the "elbow point" where adding more clusters doesn't significantly reduce inertia
4. What is the Elbow Method?
The Elbow Method is a heuristic technique to determine the optimal number of clusters (K) by plotting inertia against different K values and finding the "elbow point" where the rate of decrease sharply changes.

Process:
1. Run KMeans for K = 1, 2, 3, ..., max_K
2. Calculate inertia for each K
3. Plot K vs Inertia
4. Find the "elbow" - point where curve bends
5. Choose K at the elbow as optimal

Interpretation:
• Before elbow: Adding clusters significantly reduces inertia
• At elbow: Diminishing returns begin
• After elbow: Minimal improvement with more clusters

Limitations: Sometimes the elbow is not clear; use domain knowledge and business requirements to validate
5. What are limitations of KMeans?
1. Requires K in advance: Must specify number of clusters before training
2. Assumes spherical clusters: Struggles with non-spherical or irregular shapes
3. Sensitive to initialization: Different random starts can give different results (use kmeans++ initialization)
4. Sensitive to outliers: Extreme values can skew cluster centers
5. Assumes equal cluster sizes: Performs poorly with imbalanced clusters
6. Feature scaling required: Must normalize/standardize features
7. Categorical features: Only works with numerical data (need encoding)
8. Local optima: May converge to suboptimal solutions
9. Curse of dimensionality: Performance degrades with many features

Alternatives: DBSCAN (density-based), Hierarchical Clustering, Gaussian Mixture Models

🎯 KMeans Algorithm

KMeans is an iterative algorithm that partitions data into K distinct clusters. Each cluster is represented by its centroid (mean of all points in the cluster).

Algorithm Steps:

  1. Initialize: Randomly select K points as initial centroids (or use KMeans++ for better initialization)
  2. Assign: Assign each data point to the nearest centroid (using Euclidean distance)
  3. Update: Recalculate centroids as the mean of all points assigned to each cluster
  4. Repeat: Steps 2-3 until centroids don't change or max iterations reached

📈 Distance Metrics

Euclidean Distance (used in KMeans):

d(p, q) = √[(p₁-q₁)² + (p₂-q₂)² + ... + (pₙ-qₙ)²]

Other distance metrics:

  • Manhattan Distance: Sum of absolute differences
  • Cosine Similarity: Angle between vectors
  • Mahalanobis Distance: Accounts for correlations
